# نمونه اولیه HTML دانشگاه ملی مهارت

این پروژه یک نمونه آموزشی ساده است که فقط با HTML ساخته شده است؛ بدون CSS، JavaScript یا بک‌اند.

## اجرا
فایل `index.html` را در مرورگر باز کنید.

## انتشار در GitHub Pages
1. یک مخزن جدید در GitHub بسازید.
2. فایل `index.html` و این `README.md` را در ریشه مخزن بارگذاری کنید.
3. وارد Settings مخزن شوید.
4. در بخش Pages، گزینه انتشار از شاخه (Deploy from a branch) را انتخاب کنید.
5. شاخه `main` و پوشه `/ (root)` را انتخاب و ذخیره کنید.
6. پس از چند دقیقه، نشانی GitHub Pages مخزن نمایش داده می‌شود.

## نکته‌ها
- این یک نمونه آموزشی غیررسمی است؛ وابستگی رسمی به دانشگاه ندارد.
- نام حوزه‌های آموزشی و اطلاعیه‌ها نمونه هستند و باید با داده‌های رسمی جایگزین شوند.
- فرم تماس فقط نمایشی است و پیام‌ها را ارسال یا ذخیره نمی‌کند؛ برای ارسال واقعی به بک‌اند یا سرویس فرم نیاز است.
- در این نسخه عمداً از تگ‌های پایه HTML مانند `html`, `head`, `title`, `body`, `h1` تا `h3`, `p`, `a`, `hr`, `ul`, `ol`, `li`, `section`, `article`, `form`, `input`, `select`, `option`, `textarea`, `button` و `footer` استفاده شده است.
