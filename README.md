# دانشگاه ملی مهارت — پروژه آموزشی سه‌فایلی

- `index.html`: صفحه اصلی سایت و دو لینک کوچک در پایین صفحه.
- `Copy.html`: دریافت متن کد `index.html` برای نمایش و کپی.
- `org.html`: نسخه ساده و اصلی محتوای سایت بدون لینک‌های کمکی پایین صفحه.

## استفاده
همه سه فایل را در یک پوشه یا ریشه مخزن GitHub قرار دهید. نام فایل‌ها را دقیقاً همین‌طور نگه دارید؛ `Copy.html` و `org.html` به بزرگی و کوچکی حروف حساس‌اند.

برای GitHub Pages، هر سه فایل را در ریشه مخزن قرار دهید و از Settings → Pages انتشار شاخه `main` و پوشه `/ (root)` را فعال کنید.

نکته: بارگذاری خودکار کد در `Copy.html` با `fetch` وقتی صفحه را مستقیم از روی فایل دستگاه باز کنید ممکن است به‌دلیل محدودیت مرورگر کار نکند؛ در GitHub Pages معمولاً کار می‌کند. برای استفاده محلی، فایل‌ها را با یک سرور محلی باز کنید یا `index.html` را در ویرایشگر کد باز کنید.
