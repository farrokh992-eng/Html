# پروژه سه‌فایلی دانشگاه ملی مهارت

- `index.html`: ظاهر هشدار با نوار سبز و قرمز و دو نقطه ریز در پایین سمت چپ.
- `Copy.html`: صفحه نمایش و کپی کد اصلی.
- `org.html`: صفحه اصلی آموزشی دانشگاه ملی مهارت با کد ساده HTML.

هر سه فایل را در ریشه مخزن GitHub قرار دهید. نام فایل‌ها را دقیقاً حفظ کنید. برای نمایش کد در Copy.html، سایت باید از طریق GitHub Pages یا یک سرور محلی اجرا شود؛ بازکردن مستقیم فایل‌ها ممکن است به‌دلیل محدودیت مرورگر اجازه fetch ندهد.
